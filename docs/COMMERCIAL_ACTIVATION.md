# Commercial OlyHub activation

OlyHub is the commercial iOS/web product. Zeus Proxy is a separate repository. These changes keep the existing OlyHub API hosting configuration; they do not migrate OlyHub to Netlify.

## Implemented

- OpenRouter chat transport and explicitly configured model catalog; Gemini, OpenAI and existing Anthropic adapters can provide metered fallback. OpenRouter's hidden upstream fallback is disabled. Every application attempt obtains a server permit and consumes its original call/token allowance.
- Router chooses the cheapest quoted capable classifier/executor. Independent reviews compare actual model vendor families even when both models use OpenRouter. Level 2 text requires a completed independent review; failed review leaves a resumable draft instead of publishing an unreviewed answer as complete.
- Level 2 image generation uses one configured image model. Comparison requires a different model; Combine sends two actual private image references and owner instructions. Selection costs no model call. Signed quotes bind owner, sources, action, price and request ID. Replaying accepted actions never generates again. A fresh quote explicitly starts a new paid attempt. Every original is retained unless the user deletes it.
- Final response, assistant message and token settlement commit atomically. Replaying the exact owner/request/fingerprint returns the stored response. Retry uses a new reservation and can reuse completed stages only for the same original request/conversation and matching stage input hash. The classifier and unfinished steps remain metered. An active attempt must finish or expire before resumption.
- Content cache and checkpoints cascade with conversation/account deletion. Financial accounting does not store final response content.
- Native Apple purchases, restore, manage-subscription and terms links. RevenueCat verifies Apple StoreKit transactions; the server fetches the canonical subscriber state, checks store/environment/expiry and maps trusted entitlements to server plans. Webhook authentication is constant-time. Duplicate/out-of-order notifications fetch current state; older snapshots cannot overwrite newer snapshots. Administrative account blocks survive purchases. Expired paid subscriptions cannot obtain new permits.
- Per-account monthly USD budgets reserve conservative estimates atomically before paid attempts, including failures. Text estimates use bounded input/output plus a 25% buffer; image/web bounds require operator configuration. Plan budgets must leave the configured minimum margin against net monthly proceeds. Estimates are spending controls, not a guarantee of provider invoices. Server-only `reconcile_ai_cost` can replace a terminal request estimate with a verified invoice amount; its reference is idempotent and changes are audited. Unknown costs retain reservations.

## External configuration still required

1. OlyHub hosting authentication and server environment: Supabase URL/publishable/server-secret keys, OpenRouter/Gemini/OpenAI credentials, explicitly supported image models and conservative image/web prices. The connected Vercel tool repeatedly requested authentication; no hosting configuration or live deployment was verified in this session. Git commits are not proof of a successful deployment.
2. RevenueCat project linked to the OlyHub Apple app: public iOS SDK key, server secret and an authorization header of at least 24 characters. Point the webhook to `/api/subscription-webhook`. Use the Supabase user UUID as RevenueCat app user ID. Keep sandbox grants disabled in production. Purchases never trust a client-reported entitlement.
3. Define actual products and commercial budgets. `OLYHUB_SUBSCRIPTION_PLANS_JSON` is keyed by RevenueCat entitlement and each plan requires `monthlyCostMicrousd`, `netMonthlyRevenueMicrousd`, `dailyRequests`, `dailyTokens`, `monthlyTokens`, `maxLevel`, `allowedTiers`, `allowImage`, `allowWeb`. `minimumMargin` defaults to 0.5 and must be between 0.1 and 1. Net revenue must reflect actual Apple/tax/other deductions; budget overhead beyond model inference too. No sale prices or legal entity details were invented.
4. Apple Developer enrollment, final bundle ID/team, App Store Connect products, agreements/tax/banking, signing and physical-device/TestFlight purchase/restore/refund/renewal testing. New RevenueCat native code requires a new development/App Store build; Expo Go is not purchase validation.
5. Public privacy/terms/support URLs and actual business contact, privacy questionnaire, product metadata and review account. Existing links/manifests must be checked against actual vendors and retention policy. RevenueCat was added to billing disclosures; the native AI consent version was advanced for OpenRouter.
